## 3. Bloque 1. Consultar, modificar y recorrer listas

Una lista reúne varios valores bajo un nombre. Se escribe entre corchetes y sus elementos se separan con comas.

```python
inventario = ["espada", "escudo", "poción"]
```

Cada elemento ocupa una posición llamada **índice**. Los índices positivos comienzan en cero:

| Índice | Elemento |
| --- | --- |
| `0` | `"espada"` |
| `1` | `"escudo"` |
| `2` | `"poción"` |

La lista tiene tres elementos, pero su último índice positivo es `2`. Acceder a `inventario[3]` en esta lista produce `IndexError`.

### Ejemplo: `01_listas.py`

```python
inventario = ["espada", "escudo", "poción"]

print("Primer objeto:", inventario[0])
print("Cantidad de objetos:", len(inventario))

inventario[1] = "arco"

print("Inventario actualizado:")
for objeto in inventario:
    print("-", objeto)
```

**¿Qué sucede?**

- `inventario[0]` consulta un elemento.
- `len(inventario)` obtiene la cantidad de elementos.
- `inventario[1] = "arco"` reemplaza el escudo; la cantidad sigue siendo tres.
- `for objeto in inventario` toma un elemento por vuelta. `objeto` es una variable cuyo nombre elegimos nosotros.

**Resultado esperado:**

```text
Primer objeto: espada
Cantidad de objetos: 3
Inventario actualizado:
- espada
- arco
- poción
```

**Ahora tú:** cambia el primer objeto por `"lanza"` y agrega una instrucción que muestre el último elemento usando su índice positivo. Ejecuta y comprueba.

## 4. Bloque 2. Agregar y eliminar elementos

Un **método** es una operación asociada a un objeto. En `inventario.append("arco")`, el punto indica que la operación se aplica a esa lista.

| Operación | Efecto |
| --- | --- |
| `inventario.append("arco")` | Agrega un elemento al final. |
| `inventario.remove("escudo")` | Elimina la primera aparición de ese valor. |
| `"poción" in inventario` | Devuelve `True` si el valor está en la lista; de lo contrario, `False`. |
| `len(inventario)` | Devuelve cuántos elementos contiene. |

`remove` busca un **valor**, no un índice. Si el valor no existe, produce `ValueError`. Para evitarlo, primero comprueba su presencia con `in`.

### Ejemplo: `02_modificar_inventario.py`

```python
inventario = ["espada", "escudo", "poción"]

inventario.append("arco")
print("Después de agregar:", inventario)

objeto_a_quitar = "escudo"
if objeto_a_quitar in inventario:
    inventario.remove(objeto_a_quitar)
    print("Objeto eliminado:", objeto_a_quitar)
else:
    print("Ese objeto no está en el inventario.")

print("Inventario final:", inventario)
print("Cantidad:", len(inventario))
```

El inventario final debe ser `["espada", "poción", "arco"]`, con tres elementos. Python puede mostrar los textos con comillas simples; representan los mismos valores.

> `append` y `remove` modifican la lista directamente. Escribe `inventario.append("arco")`, **no** `inventario = inventario.append("arco")`: este último código sustituye la lista por `None`.

**Comprueba:** cambia `objeto_a_quitar` por `"llave"`. El programa debe informar que no existe y conservar los cuatro objetos.

## 5. Bloque 3. Definir y llamar funciones

Una función es un bloque de instrucciones con un nombre. **Definirla** indica qué hará; **llamarla** ejecuta sus instrucciones.

### Ejemplo: `03_funciones.py`

```python
def mostrar_menu():
    print("1. Atacar")
    print("2. Curar")
    print("3. Ver inventario")
    print("4. Salir")


mostrar_menu()
```

- `def` inicia la definición.
- `mostrar_menu` es el nombre que elegimos.
- Los paréntesis vacíos indican que esta función no recibe argumentos.
- Los dos puntos y la indentación delimitan el bloque.
- `mostrar_menu()` llama a la función. Sin esta línea, definirla no muestra el menú.

**Comprueba:** llama a la función dos veces. Después deja una sola llamada. No necesitas copiar sus cuatro instrucciones para reutilizarlas.

## 6. Bloque 4. Parámetros, argumentos y retorno

Un **parámetro** es una variable que recibe un dato dentro de una función. Un **argumento** es el valor que le proporcionamos al llamarla.

### Ejemplo: `04_retorno.py`

```python
def calcular_danio(ataque, defensa):
    danio = ataque - defensa
    if danio < 0:
        danio = 0
    return danio


danio_causado = calcular_danio(15, 8)
print("Daño causado:", danio_causado)

vida_enemigo = 30
vida_enemigo = vida_enemigo - danio_causado
print("Vida del enemigo:", vida_enemigo)
```

En la definición, `ataque` y `defensa` son parámetros. En la llamada, `15` y `8` son argumentos. Se asignan por posición: `ataque` recibe `15` y `defensa` recibe `8`.

`return danio` termina la llamada y entrega su resultado al código que la llamó. La variable `danio` pertenece a la función; fuera de ella guardamos el resultado en `danio_causado`.

**Resultado esperado:** daño `7` y vida del enemigo `23`.

### `print` y `return` cumplen tareas distintas

| Instrucción | ¿Para qué sirve? |
| --- | --- |
| `print(danio)` | Muestra el valor en la consola. |
| `return danio` | Entrega el valor al código que llamó a la función para guardarlo, compararlo o usarlo en una operación. |

Una función sin `return` explícito devuelve `None`. `mostrar_menu()` puede no devolver un valor útil porque su propósito es mostrar opciones; `calcular_danio()` necesita devolver un número para usarlo después.

**Comprueba:** prueba `calcular_danio(8, 15)`, `calcular_danio(10, 10)` y `calcular_danio(20, 5)`. Los resultados deben ser `0`, `0` y `15`. La regla evita que una defensa alta produzca daño negativo.

## 7. Bloque 5. Integrar listas y funciones

### Ejemplo guiado: `05_inventario.py`

```python
def mostrar_inventario(objetos):
    print("Inventario del jugador:")
    if len(objetos) == 0:
        print("El inventario está vacío.")
    else:
        for objeto in objetos:
            print("-", objeto)
    print("Total de objetos:", len(objetos))


inventario = ["espada", "escudo", "poción"]
mostrar_inventario(inventario)

nuevo_objeto = input("¿Qué objeto quieres agregar? ")
if nuevo_objeto != "":
    inventario.append(nuevo_objeto)
else:
    print("No se agregó un objeto sin nombre.")

mostrar_inventario(inventario)
```

`objetos` es el parámetro e `inventario` es el argumento. No necesitan tener el mismo nombre. La función recorre la lista que recibe; no crea otra lista ni reinicia el inventario.

En este ejemplo, la validación rechaza presionar Enter sin escribir nada. Todavía no rechaza nombres formados solamente por espacios.

## 8. Actividad de comprobación. Combate con inventario

Crea `06_combate.py`. Construye tu programa usando los ejemplos anteriores como referencia. En esta actividad integrarás listas, funciones, decisiones y repetición; no se proporciona la solución completa.

### 8.1 Reglas del juego

| Dato | Valor inicial o regla |
| --- | --- |
| Vida del jugador | `60`, con máximo de `100`. |
| Vida del enemigo | `100`. |
| Daño de cada ataque | `20`. |
| Recuperación por poción | `25`, sin superar `100`. |
| Inventario inicial | `["espada", "poción", "poción"]`. |
| Acciones | `1`: atacar; `2`: curar; `3`: ver inventario; `4`: salir. |

El enemigo no contraataca en esta versión. El objetivo es practicar funciones y actualización de datos. La partida finaliza al reducir su vida a cero o al seleccionar salir.

### 8.2 Funciones que debes escribir

| Función | Responsabilidad |
| --- | --- |
| `mostrar_menu()` | Mostrar las cuatro opciones. |
| `mostrar_inventario(objetos)` | Mostrar cada objeto y la cantidad total; indicar si la lista está vacía. |
| `atacar(vida_enemigo, danio)` | Restar el daño y devolver la nueva vida, sin permitir valores menores que cero. |
| `curar(vida_jugador, cantidad)` | Sumar la cantidad y devolver la nueva vida, sin permitir valores mayores que cien. |

Las funciones `atacar` y `curar` reciben números no negativos. Usa los valores de la tabla; no es necesario pedir cantidades al usuario.

**Detalle clave:** si una función devuelve la vida actualizada, debes guardar ese resultado:

```python
vida_enemigo = atacar(vida_enemigo, 20)
```

Escribir solamente `atacar(vida_enemigo, 20)` calcula el resultado, pero no actualiza la variable del programa principal.

11. Fuera del ciclo, muestra victoria si la vida del enemigo es cero; en caso contrario, muestra que el jugador salió de la partida.

### 8.4 ¿Cuándo se consume una poción?

- Si la vida ya es `100`, informa que está completa y no consumas ninguna.
- Si falta vida y existe `"poción"` en el inventario, llama a `curar`, guarda la nueva vida y elimina **una sola** poción con `remove`.
- Si falta vida pero no hay pociones, informa que no quedan y conserva la vida.

La lista comienza con dos pociones. Cada uso válido elimina la primera coincidencia; la otra permanece hasta el siguiente uso.

## 10. Errores frecuentes

| Problema | Qué revisar |
| --- | --- |
| `IndexError` | El índice debe existir; una lista de tres elementos tiene índices positivos `0`, `1` y `2`. |
| `ValueError` al eliminar | Comprueba con `in` antes de usar `remove`. |
| Aparece `None` al guardar un resultado | Revisa si la función tiene `return` o si asignaste el resultado de `append` o `remove`. |
| La vida no cambia | Guarda el valor devuelto en la variable correspondiente. |
| La función no hace nada | Asegúrate de llamarla usando paréntesis. |
| El menú no reconoce `1` | Compara el texto de `input` con `"1"`, no con el número `1`. |
| La vida se reinicia en cada turno | Coloca los valores iniciales antes del `while`. |
| Error de indentación | Usa cuatro espacios por nivel y revisa qué instrucciones pertenecen a cada bloque. |
