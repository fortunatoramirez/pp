# Práctica 9. Animación con sprites y diseño de personajes con IA

**Asignatura:** Principios de Programación  
**Base:** [Práctica 8: Pygame](p-8.md).  
**Objetivo:** animar y mover un personaje; después sustituir sus imágenes por un diseño creado con ayuda de inteligencia artificial.

Un **sprite** es una imagen que representa un elemento del juego. Un **fotograma** o *frame* es una imagen de una animación. Al alternar varios fotogramas vemos un cambio de postura; al cambiar X e Y desplazamos al personaje. **Animar y desplazar son operaciones distintas.**

## 1. Preparar el dinosaurio

Descarga [Free Dino Sprites de Game Art 2D](https://www.gameart2d.com/free-dino-sprites.html), extrae el ZIP y busca la carpeta `png`.

Crea `practica_9`, con `main.py` y dos subcarpetas: `assets/dino` y `assets/ia`. Copia en `assets/dino` los **10 archivos `Idle (1).png` a `Idle (10).png`** y los **10 archivos `Walk (1).png` a `Walk (10).png`**. Mantén exactamente sus nombres, espacios y paréntesis. Usaremos las secuencias completas.

- `Idle`: reposo.
- `Walk`: caminar.
- `assets/ia`: déjala vacía hasta terminar la primera versión.

Si hace falta instalar Pygame, ejecuta `python -m pip install pygame` en la terminal del mismo intérprete que usas en VS Code.

## 2. Ejecutar la animación base

Escribe este programa en **`main.py`**. Haz clic en la ventana y mueve con WASD o flechas; X o Escape cierran. No requiere Enter.

```python
from pathlib import Path
import pygame

pygame.init()
ANCHO, ALTO = 800, 500
TAM = 128
VELOCIDAD = 200.0        # Píxeles por segundo
FPS_ANIM = 8.0          # Imágenes de animación por segundo
CARPETA = "dino"
N_IDLE, N_WALK = 10, 10
ventana = pygame.display.set_mode((ANCHO, ALTO))
pygame.display.set_caption("Práctica 9 - Sprites")
reloj = pygame.time.Clock()
base = Path(__file__).resolve().parent / "assets" / CARPETA


def cargar_frames(nombre, cantidad):
    frames = []
    for numero in range(1, cantidad + 1):
        ruta = base / f"{nombre} ({numero}).png"
        imagen = pygame.image.load(str(ruta)).convert_alpha()
        ancho, alto = imagen.get_size()
        escala = min(TAM / ancho, TAM / alto)
        medida = (max(1, round(ancho * escala)), max(1, round(alto * escala)))
        imagen = pygame.transform.smoothscale(imagen, medida)
        lienzo = pygame.Surface((TAM, TAM), pygame.SRCALPHA)
        lienzo.blit(imagen, ((TAM - medida[0]) // 2, TAM - medida[1]))
        frames.append(lienzo)
    return frames


idle = cargar_frames("Idle", N_IDLE)
walk = cargar_frames("Walk", N_WALK)
x, y = 100.0, 220.0
estado = "Idle"
indice = 0.0
mira_izquierda = False
corriendo = True

while corriendo:
    dt = min(reloj.tick(60) / 1000.0, 0.05)
    for evento in pygame.event.get():
        if evento.type == pygame.QUIT:
            corriendo = False
        elif evento.type == pygame.KEYDOWN:
            if evento.key in (pygame.K_x, pygame.K_ESCAPE):
                corriendo = False
    if not corriendo:
        break

    teclas = pygame.key.get_pressed()
    dx, dy = 0, 0
    if teclas[pygame.K_a] or teclas[pygame.K_LEFT]:
        dx -= 1
    if teclas[pygame.K_d] or teclas[pygame.K_RIGHT]:
        dx += 1
    if teclas[pygame.K_w] or teclas[pygame.K_UP]:
        dy -= 1
    if teclas[pygame.K_s] or teclas[pygame.K_DOWN]:
        dy += 1
    if dx != 0 and dy != 0:
        dx /= 2 ** 0.5
        dy /= 2 ** 0.5

    anterior_x, anterior_y = x, y
    x = max(0.0, min(x + dx * VELOCIDAD * dt, ANCHO - TAM))
    y = max(0.0, min(y + dy * VELOCIDAD * dt, ALTO - TAM))
    if dx != 0:
        mira_izquierda = dx < 0

    nuevo_estado = "Idle"
    if x != anterior_x or y != anterior_y:
        nuevo_estado = "Walk"
    if nuevo_estado != estado:
        estado = nuevo_estado
        indice = 0.0

    frames = idle if estado == "Idle" else walk
    imagen = frames[int(indice)]
    indice = (indice + FPS_ANIM * dt) % len(frames)
    if mira_izquierda:
        imagen = pygame.transform.flip(imagen, True, False)

    ventana.fill((35, 45, 60))
    ventana.blit(imagen, (round(x), round(y)))
    pygame.display.flip()

pygame.quit()
```

**Resultado esperado:** el dinosaurio anima su reposo, camina al desplazarse, mira a izquierda o derecha y permanece dentro de la ventana. Arriba y abajo lo desplazan conservando su vista lateral; no estamos creando nuevas perspectivas.

## 3. Entender y probar antes de usar IA

| Parte | Qué hace |
|---|---|
| `cargar_frames` | Carga en orden numérico, conserva transparencia y ajusta las imágenes a un lienzo de 128 × 128 sin deformarlas. |
| `range(1, cantidad + 1)` | Incluye desde el archivo 1 hasta el último. |
| `FPS_ANIM * dt` | Avanza la animación según el tiempo transcurrido. Es independiente de la velocidad de desplazamiento. |
| `int(indice)` y `% len(frames)` | Seleccionan un fotograma y hacen que la secuencia vuelva al inicio. |
| Cambio de `estado` | Reinicia el índice al pasar entre reposo y caminar. |
| `transform.flip` | Refleja horizontalmente la imagen para mirar a la izquierda. |

`frames = idle if estado == "Idle" else walk` equivale a seleccionar `idle` dentro de un `if` y `walk` dentro de su `else`. El límite de `dt` evita saltos grandes tras una interrupción; con una computadora muy lenta la simulación puede ralentizarse, como en la práctica 8.

Realiza estas pruebas **una por una** y restaura los valores originales:

1. Cambia `FPS_ANIM` de 8 a 2: las posturas deben cambiar más despacio, pero el personaje debe desplazarse igual de rápido.
2. Cambia `VELOCIDAD` de 200 a 100: debe desplazarse más despacio sin cambiar la frecuencia de animación.
3. Inicia con `FPS_ANIM = 0`: el personaje se desplaza con una imagen fija para cada estado. Explica por qué eso sigue siendo movimiento.
4. Suelta las teclas, cambia de dirección y alcanza los cuatro bordes. Comprueba reposo, reflejo y límites.

**Guarda una captura o video del dinosaurio funcionando antes de continuar.**

## 4. Crear tu personaje con inteligencia artificial

Ahora usarás IA como apoyo para **diseñar los recursos visuales**. Puedes utilizar [Adobe Firefly](https://www.adobe.com/products/firefly/features/text-to-image.html), que permite generar imágenes desde texto y trabajar con imágenes de referencia, u otra IA de imágenes a la que tengas acceso. No es necesario contratar un plan para esta actividad: si tu acceso es limitado, trabaja en equipo y completa los ajustes manualmente.

Primero genera un personaje original de cuerpo completo, de perfil hacia la derecha. Después usa esa imagen como referencia para pedir sus variaciones. **La IA propone imágenes; tú revisas y corriges si realmente sirven para animar.**

**Prompt inicial:**

> Diseña un personaje original para un videojuego 2D: [describe tu personaje]. Cuerpo completo, vista lateral mirando a la derecha, estilo caricatura sencillo, colores definidos. Pose de reposo, sin texto ni objetos alrededor. Fondo transparente si la herramienta lo permite; de lo contrario, un fondo liso de un color que no aparezca en el personaje.

**Prompt para las poses, adjuntando tu personaje de referencia:**

> Conserva exactamente el personaje, colores, proporciones y vista lateral. Crea cuatro poses consecutivas de caminar: contacto de un pie, paso intermedio, contacto del pie contrario y regreso. Mantén el mismo tamaño del cuerpo y la misma línea de apoyo de los pies. No cortes ninguna parte del personaje. Entrega las poses separadas o en cuatro celdas iguales, sin texto. Después necesito tres poses de reposo con cambios sutiles de respiración.

Si la herramienta entrega una hoja con varias poses, **recorta y exporta cada celda como un PNG individual**. Este programa carga archivos separados, no recorta hojas automáticamente. Si repite la misma pose o cambia de personaje, solicita una corrección específica; no basta con renombrar cuatro copias de la misma imagen.

## 5. Preparar las imágenes y sustituir el personaje

En un editor de imágenes que permita transparencia:

1. Quita el fondo si existe. Un tablero de cuadritos dibujado dentro de la imagen **no es transparencia real**; compruébalo colocando la imagen sobre un fondo de color.
2. Coloca cada pose en un lienzo transparente de **256 × 256 píxeles**, con el mismo tamaño aparente del personaje y la misma altura de apoyo de los pies. No recortes cada pose al ras ni la estires por separado.
3. Exporta en `assets/ia` tres PNG llamados `Idle (1).png` a `Idle (3).png` y cuatro llamados `Walk (1).png` a `Walk (4).png`.
4. En `main.py`, cambia únicamente:

```python
CARPETA = "ia"
N_IDLE, N_WALK = 3, 4
```

**Resultado:** el nuevo personaje debe moverse y animarse con los mismos controles. Conserva `assets/dino` para poder comparar. Cambiar los archivos de imagen no requiere reescribir el movimiento.

La IA no garantiza poses consistentes ni un ciclo perfecto. Si el personaje “salta”, revisa la alineación de los pies; si cambia de tamaño, revisa la escala; si el paso se corta al repetir, ajusta la última pose respecto de la primera. Puedes corregir las poses manualmente: eso forma parte del trabajo.

## 6. Comprobar y entregar

| Comprobación | Debe cumplirse con ambos personajes |
|---|---|
| Reposo y caminar | Se distinguen; las imágenes cambian en secuencia. |
| Dirección y límites | Mira a izquierda/derecha y no sale de la ventana. |
| Transparencia | No aparece un bloque de fondo alrededor. |
| Consistencia | No cambia de identidad ni de tamaño entre poses. |
| Cambio de recursos | Funciona cambiando carpeta y cantidades, sin alterar los controles. |

**Entrega:** carpeta con `main.py` y ambas colecciones de imágenes; video breve del dinosaurio y del personaje nuevo; nombre de la IA, prompts usados y una corrección que realizaste. Incluye el enlace al recurso original del dinosaurio.

**Responde brevemente:** ¿qué diferencia hay entre animar y desplazar?, ¿qué parte aportó la IA y qué corregiste tú?, ¿por qué todos los fotogramas necesitan una escala y alineación consistentes?

**Si algo falla:** `FileNotFoundError` suele indicar ruta o nombre incorrecto; un fondo visible se corrige en la imagen, no con `convert_alpha()`; un personaje deformado o que tiembla exige revisar sus fotogramas. Guarda el archivo y vuelve a ejecutar después de cambiar las cantidades.
