## 3. ¿Qué estructura conviene utilizar?

Imagina que necesitas representar un videojuego:

| Información | Estructura | Ejemplo | Forma de consultar |
|---|---|---|---|
| Varios nombres de personajes | Lista | `["Mago", "Arquero"]` | Por índice: `nombres[0]` |
| Un par de coordenadas | Tupla | `(15, 30)` | Por índice: `posicion[0]` |
| Los atributos de un personaje | Diccionario | `{"nombre": "Mago", "vida": 60}` | Por clave: `personaje["vida"]` |

Las listas y las tuplas tienen índices que comienzan en **0**. En los diccionarios de esta práctica, las claves son textos que identifican cada dato.

Una lista permite cambiar sus elementos. Una tupla no permite reemplazar, agregar o eliminar sus elementos después de crearla. Un diccionario permite actualizar valores y agregar o eliminar pares clave–valor.

> Usar una tupla para una posición no impide que el personaje se mueva: se puede crear otra tupla y asignarla a la variable. Lo que no se permite es cambiar una coordenada dentro de la tupla existente. En esta práctica las tuplas contienen números; una tupla también podría contener objetos mutables, como listas, cuyo contenido sí puede cambiar.

## 4. Desarrollo paso a paso

### Paso 1. Crear y consultar una tupla

```python
posicion_jugador = (15, 30)

print("Posición del jugador:", posicion_jugador)
print("Coordenada X:", posicion_jugador[0])
print("Coordenada Y:", posicion_jugador[1])
```

Resultado esperado:

```text
Posición del jugador: (15, 30)
Coordenada X: 15
Coordenada Y: 30
```

En este ejemplo acordamos que el primer elemento representa X y el segundo representa Y. Python almacena los valores; el significado de cada posición lo definimos nosotros.

**Comprueba:** cambia la posición inicial por `(8, 12)` y ejecuta de nuevo. Después restablece `(15, 30)` para seguir los ejemplos.

### Paso 2. Comprender qué significa «inmutable»

Agrega y ejecuta temporalmente esta instrucción:

```python
posicion_jugador[0] = 20
```

Python mostrará un `TypeError`: no se puede asignar un valor a un elemento de una tupla. Este error es intencional para observar su comportamiento.

**Comenta o elimina esa instrucción antes de continuar.** Un error detiene la ejecución y evita que se ejecuten las instrucciones siguientes.

Para representar una nueva posición, asigna una nueva tupla:

```python
posicion_jugador = (20, 30)
print("Nueva posición:", posicion_jugador)
```

Resultado esperado: `Nueva posición: (20, 30)`.

**Explica:** ¿por qué la segunda instrucción de asignación sí está permitida?

### Paso 3. Crear y consultar un diccionario

Un diccionario reúne pares **clave: valor** dentro de llaves `{}`. Cada clave identifica un dato y debe ser única dentro del diccionario.

```python
personaje = {
    "nombre": "Archer",
    "vida": 80,
    "mana": 50,
    "arma": "Arco"
}

print("Nombre:", personaje["nombre"])
print("Vida:", personaje["vida"])
print("Arma:", personaje["arma"])
```

En `"vida": 80`, la clave es `"vida"` y el valor es `80`. Los valores pueden ser de distintos tipos: aquí hay textos y números enteros.

Para consultar la vida escribimos `personaje["vida"]`. Las comillas indican que la clave es un texto; debe coincidir exactamente con la que se guardó.

**Comprueba:** agrega una instrucción que muestre el maná del personaje.

### Paso 4. Modificar valores y agregar claves

```python
personaje["vida"] = 90
personaje["arma"] = "Ballesta"
personaje["nivel"] = 5

print("Estado actualizado:", personaje)
```

La misma forma de asignación tiene dos efectos:

- Si la clave ya existe, **actualiza su valor**, como sucede con `"vida"` y `"arma"`.
- Si la clave no existe, **agrega un nuevo par**, como sucede con `"nivel"`.

También puedes calcular un nuevo valor a partir del anterior:

```python
personaje["vida"] = personaje["vida"] - 20
print("Vida después del ataque:", personaje["vida"])
```

Si ejecutas todos los bloques en orden, la vida resultante será **70**.

**Comprueba:** agrega 10 puntos al maná usando su valor actual y muestra el resultado. Debe pasar de 50 a 60.

### Paso 5. Guardar una tupla dentro de un diccionario

```python
personaje["posicion"] = posicion_jugador

print("Posición:", personaje["posicion"])
print("Coordenada X:", personaje["posicion"][0])
print("Coordenada Y:", personaje["posicion"][1])
```

Lee `personaje["posicion"][0]` en dos partes:

1. `personaje["posicion"]` obtiene la tupla `(20, 30)`.
2. `[0]` obtiene su primer elemento: `20`.

Para mover al personaje, reemplaza el valor de la clave por otra tupla:

```python
personaje["posicion"] = (25, 30)
print("Posición después de moverse:", personaje["posicion"])
```

Esto modifica el diccionario al guardar una nueva tupla. No modifica los elementos de la tupla anterior. La variable `posicion_jugador` conserva `(20, 30)`.

### Paso 6. Recorrer diccionarios y listas de diccionarios

**A. Mostrar los datos de un personaje**

```python
for clave, valor in personaje.items():
    print(clave, ":", valor)
```

`items()` permite recorrer los pares clave–valor. En cada repetición, `clave` recibe una etiqueta y `valor` recibe su contenido. La instrucción con sangría se ejecuta una vez por cada par.

**B. Mostrar varios personajes**

```python
personajes = [
    {"nombre": "Mago", "vida": 60, "mana": 100},
    {"nombre": "Guerrero", "vida": 120, "mana": 30},
    {"nombre": "Arquero", "vida": 80, "mana": 50}
]

for personaje_actual in personajes:
    print(personaje_actual["nombre"],
          "→ Vida:", personaje_actual["vida"],
          "Maná:", personaje_actual["mana"])
```

La lista `personajes` contiene tres diccionarios. En cada repetición, `personaje_actual` representa uno de ellos.

También puedes consultar un personaje específico:

```python
print("Nombre del primer personaje:", personajes[0]["nombre"])
```

Primero `[0]` selecciona el primer diccionario; después `["nombre"]` consulta su nombre. El resultado es `Mago`.

**Comprueba:** agrega un cuarto personaje directamente en la definición de la lista y ejecuta el ciclo otra vez. No necesitas utilizar `append()`.

## 7. Errores frecuentes

| Situación | Causa | Cómo corregirla |
|---|---|---|
| `TypeError` al cambiar una coordenada | Se intenta modificar un elemento de una tupla | Asigna una nueva tupla |
| `KeyError` al consultar un atributo | La clave no existe o está escrita diferente | Verifica comillas, mayúsculas y acentos; `"vida"` y `"Vida"` son claves distintas |
| `IndexError` al consultar una posición | El índice está fuera de los elementos disponibles | Para una tupla de dos elementos utiliza `0` o `1` |
| Error al comparar nivel con un número | El nivel se conservó como texto | Convierte la entrada a entero con `int()` |
| Error de sintaxis en una colección | Falta una coma, comilla o cierre | Revisa las comas entre elementos y los pares `[]`, `()` y `{}` |
| El ciclo o la condición no funcionan como se espera | La sangría no corresponde al bloque | Usa cuatro espacios por nivel de sangría |
