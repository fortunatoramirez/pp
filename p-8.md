### Paso 3. Crear una ventana que responda

**Archivo nuevo:** escribe este programa completo en `movimiento.py`.

```python
import pygame

pygame.init()
ANCHO = 640
ALTO = 480
pantalla = pygame.display.set_mode((ANCHO, ALTO))
pygame.display.set_caption("Práctica 8 - Primer movimiento")
reloj = pygame.time.Clock()

# DATOS INICIALES
activo = True

while activo:
    # TIEMPO
    reloj.tick(60)

    # EVENTOS
    for evento in pygame.event.get():
        if evento.type == pygame.QUIT:
            activo = False

    if not activo:
        break

    # ACTUALIZACION

    # DIBUJO
    pantalla.fill((25, 30, 40))
    pygame.display.flip()

pygame.quit()
```

**Resultado:** una ventana oscura que cierra con su botón de cerrar.

- `pygame.init()` inicializa módulos de la biblioteca.
- `set_mode` crea la superficie de la ventana y la devuelve; la guardamos en `pantalla`.
- `event.get()` retira los eventos pendientes. `QUIT` avisa que se solicitó cerrar la ventana.
- `fill` pinta el fondo; `flip` presenta el cuadro dibujado.
- `tick(60)` limita aproximadamente la frecuencia del ciclo a 60 cuadros por segundo; no garantiza que la computadora los alcance.
- `pygame.quit()` libera los módulos al terminar.

**Prueba:** cambia solamente el color del fondo. **Explica:** ¿por qué seguimos revisando eventos aunque aún no haya jugador?

### Paso 8. Separar dirección y desplazamiento

**Archivo:** `movimiento.py`. Reemplaza todo el bloque de actualización del paso 7 por:

```python
    teclas = pygame.key.get_pressed()
    dx = 0
    dy = 0
    if teclas[pygame.K_a] or teclas[pygame.K_LEFT]:
        dx = dx - 1
    if teclas[pygame.K_d] or teclas[pygame.K_RIGHT]:
        dx = dx + 1
    if teclas[pygame.K_w] or teclas[pygame.K_UP]:
```

### Paso 12. Punto de comprobación: movimiento completo

Compara tu archivo con esta versión. Si necesitas reconstruirlo, **reemplaza todo `movimiento.py`**; no dupliques instrucciones.

```python
import pygame

pygame.init()
ANCHO = 640
ALTO = 480
TAM = 32
VELOCIDAD = 200.0
pantalla = pygame.display.set_mode((ANCHO, ALTO))
pygame.display.set_caption("Práctica 8 - Movimiento")
reloj = pygame.time.Clock()
x = 80.0
y = 120.0
activo = True

while activo:
    dt = reloj.tick(60) / 1000.0
    for evento in pygame.event.get():
        if evento.type == pygame.QUIT:
            activo = False
        elif evento.type == pygame.KEYDOWN:
            if evento.key == pygame.K_SPACE:
                print("Recibí una pulsación de espacio")
            elif evento.key == pygame.K_x or evento.key == pygame.K_ESCAPE:
                activo = False
    if not activo:
        break

    teclas = pygame.key.get_pressed()
    dx = 0
    dy = 0
    if teclas[pygame.K_a] or teclas[pygame.K_LEFT]:
        dx = dx - 1
    if teclas[pygame.K_d] or teclas[pygame.K_RIGHT]:
        dx = dx + 1
    if teclas[pygame.K_w] or teclas[pygame.K_UP]:
        dy = dy - 1
    if teclas[pygame.K_s] or teclas[pygame.K_DOWN]:
        dy = dy + 1
    if dx != 0 and dy != 0:
        dx = dx / (2 ** 0.5)
        dy = dy / (2 ** 0.5)
    x = x + dx * VELOCIDAD * dt
    y = y + dy * VELOCIDAD * dt
    x = max(0.0, min(x, ANCHO - TAM))
    y = max(0.0, min(y, ALTO - TAM))

    pantalla.fill((25, 30, 40))
    pygame.draw.rect(pantalla, (70, 220, 130), (round(x), round(y), TAM, TAM))
    pygame.display.flip()

pygame.quit()
```

`round` obtiene la coordenada entera para dibujar sin perder los decimales acumulados en X e Y. **Antes de seguir:** demuestra movimiento, detención al soltar, diagonales, límites y cierre.

### Paso 22. Pausa, victoria y derrota

**Lectura:** este fragmento se integrará en el siguiente programa, no se pega en `colisiones.py`.

```python
if estado["modo"] == "jugando":
    actualizar(estado, teclas, dt)
```

Solo se actualiza la partida mientras se juega. Los eventos y el dibujo siguen ejecutándose en los demás modos.

| Modo | Robot, dron y protección | P | R | X / Escape / cerrar |
|---|---|---|---|---|
| `jugando` | Se actualizan | Pausar | Sin efecto | Cerrar |
| `pausa` | Se congelan | Continuar | Sin efecto | Cerrar |
| `victoria` | Se congelan | Sin efecto | Reiniciar | Cerrar |
| `derrota` | Se congelan | Sin efecto | Reiniciar | Cerrar |

**Regla de resultado:** primero se aplica daño. Si las vidas llegan a cero, hay derrota y no se recoge una batería en ese cuadro. En otro caso, se recogen baterías y, si no queda ninguna, hay victoria.

**Explica:** ¿por qué el `for evento ...` no debe quedar dentro de `if modo == "jugando"`?

### Paso 23. Ordenar las responsabilidades

La versión final organiza en funciones lo que ya probaste. Antes de copiarla, identifica qué código corresponde a cada una:

| Función | Responsabilidad | Qué no debe hacer |
|---|---|---|
| `nueva_partida` | Construir los datos iniciales. | Dibujar o esperar teclas. |
| `mover_jugador` | Dirección, desplazamiento, límites y rectángulo actualizado. | Restar vidas. |
| `rapidez_enemigo` | Elegir rapidez según puntos. | Cambiar dirección. |

Un `return` sin valor sale de la función. Una función que recibe `estado` puede modificar sus entradas porque trabaja sobre el diccionario recibido.

```python
            pygame.Rect(120, 160, 24, 24),

            pygame.Rect(480, 380, 24, 24)
        ],
        "enemigo_x": 20.0,
        "enemigo": pygame.Rect(20, 280, 40, 32),
        "direccion": 1,
        "vidas": 3,
        "puntos": 0,
        "proteccion": 0.0,
        "modo": "jugando"
    }


def rapidez_enemigo(puntos):
    if puntos < 10:
        return 100.0
    elif puntos < 20:
        return 140.0
    else:
        return 180.0


def mover_jugador(estado, teclas, dt):
    dx = 0
    dy = 0
    if teclas[pygame.K_a] or teclas[pygame.K_LEFT]:
        dx = dx - 1
    if teclas[pygame.K_d] or teclas[pygame.K_RIGHT]:
        dx = dx + 1
    if teclas[pygame.K_w] or teclas[pygame.K_UP]:
        dy = dy - 1
    if teclas[pygame.K_s] or teclas[pygame.K_DOWN]:
        dy = dy + 1
    if dx != 0 and dy != 0:
        dx = dx / (2 ** 0.5)
        dy = dy / (2 ** 0.5)

    estado["x"] = estado["x"] + dx * VELOCIDAD * dt
    estado["y"] = estado["y"] + dy * VELOCIDAD * dt
    estado["x"] = max(float(CAMPO.left), min(estado["x"], CAMPO.right - TAM))
    estado["y"] = max(float(CAMPO.top), min(estado["y"], CAMPO.bottom - TAM))
    estado["jugador"].topleft = (round(estado["x"]), round(estado["y"]))


def actualizar(estado, teclas, dt):
    if estado["modo"] != "jugando":
        return

    estado["proteccion"] = max(0.0, estado["proteccion"] - dt)
    mover_jugador(estado, teclas, dt)

    rapidez = rapidez_enemigo(estado["puntos"])
    estado["enemigo_x"] = estado["enemigo_x"] + estado["direccion"] * rapidez * dt
    limite = CAMPO.right - estado["enemigo"].width
    if estado["enemigo_x"] >= limite:
        estado["enemigo_x"] = float(limite)
        estado["direccion"] = -1
    elif estado["enemigo_x"] <= CAMPO.left:
        estado["enemigo_x"] = float(CAMPO.left)
        estado["direccion"] = 1
    estado["enemigo"].x = round(estado["enemigo_x"])

    if estado["jugador"].colliderect(estado["enemigo"]) and estado["proteccion"] <= 0:
        estado["vidas"] = max(0, estado["vidas"] - 1)
        estado["proteccion"] = 1.0
        estado["x"] = 80.0
        estado["y"] = 120.0
        estado["jugador"].topleft = (80, 120)
        if estado["vidas"] == 0:
            estado["modo"] = "derrota"
            return

    for bateria in estado["baterias"].copy():
        if estado["jugador"].colliderect(bateria):
            estado["baterias"].remove(bateria)
            estado["puntos"] = estado["puntos"] + 10
    if len(estado["baterias"]) == 0:
        estado["modo"] = "victoria"


def dibujar(pantalla, fuente, estado):
    pantalla.fill((25, 30, 40))
    pygame.draw.rect(pantalla, (65, 75, 90), CAMPO, 2)
    for bateria in estado["baterias"]:
        pygame.draw.rect(pantalla, (255, 210, 60), bateria)
    pygame.draw.rect(pantalla, (230, 80, 80), estado["enemigo"])
    color_jugador = (70, 220, 130)
    if estado["proteccion"] > 0:
        color_jugador = (245, 245, 245)
    pygame.draw.rect(pantalla, color_jugador, estado["jugador"])

    texto = "Vidas: " + str(estado["vidas"]) + "   Puntos: " + str(estado["puntos"])
    pantalla.blit(fuente.render(texto, True, (240, 240, 240)), (12, 10))
    ayuda = "WASD/flechas: mover | P: pausa | R: reinicio al terminar | X: salir"
    pantalla.blit(fuente.render(ayuda, True, (220, 220, 220)), (12, 40))

    mensaje = ""
    if estado["modo"] == "pausa":
        mensaje = "PAUSA - P para continuar"
    elif estado["modo"] == "victoria":
        mensaje = "RESCATE COMPLETO - R para reiniciar"
    elif estado["modo"] == "derrota":
        mensaje = "SIN VIDAS - R para reiniciar"
    if mensaje != "":
        pygame.draw.rect(pantalla, (10, 15, 25), (60, 215, 520, 50))
        pantalla.blit(fuente.render(mensaje, True, (255, 255, 255)), (80, 230))
    pygame.display.flip()


def main():
    pygame.init()
    pantalla = pygame.display.set_mode((ANCHO, ALTO))
    pygame.display.set_caption("Práctica 8 - Rescate gráfico")
    fuente = pygame.font.Font(None, 22)
    reloj = pygame.time.Clock()
    estado = nueva_partida()
    activo = True

    while activo:
        dt = min(reloj.tick(FPS) / 1000.0, 0.05)
        omitir_actualizacion = False
        for evento in pygame.event.get():
            if evento.type == pygame.QUIT:
                activo = False
            elif evento.type == pygame.KEYDOWN:
                if evento.key in (pygame.K_x, pygame.K_ESCAPE):
                    activo = False
                elif evento.key == pygame.K_p:
                    if estado["modo"] == "jugando":
                        estado["modo"] = "pausa"
                        omitir_actualizacion = True
                    elif estado["modo"] == "pausa":
                        estado["modo"] = "jugando"
                        omitir_actualizacion = True
                elif evento.key == pygame.K_r and estado["modo"] in ("victoria", "derrota"):
                    estado = nueva_partida()
                    omitir_actualizacion = True
        if not activo:
            break

        teclas = pygame.key.get_pressed()
        if not omitir_actualizacion:
            actualizar(estado, teclas, dt)
        dibujar(pantalla, fuente, estado)

    pygame.quit()


if __name__ == "__main__":
    main()
```

### Paso 25. Comprender los últimos detalles de integración

Lee una diferencia a la vez:

1. **Decimales y rectángulos:** `estado["x"]` y `estado["y"]` conservan fracciones. `jugador.topleft` actualiza las coordenadas enteras del rectángulo para dibujar y detectar colisiones. Deben sincronizarse después de mover y después de reaparecer.
2. **Propiedades del campo:** `left`, `top`, `right` y `bottom` describen sus bordes. `enemigo.width` permite calcular hasta dónde cabe el dron.
3. **Pausa:** seguimos llamando a `tick` y procesando eventos. `actualizar` regresa inmediatamente si el modo no es `jugando`; también se congela la protección.
4. **Transiciones:** `omitir_actualizacion` evita mover usando el intervalo anterior justo en el cuadro de reanudar o reiniciar. El nuevo estado se dibuja primero.
5. **Intervalo máximo:** `min(..., 0.05)` limita el avance simulado a 50 ms por cuadro para evitar saltos enormes después de una interrupción. Si la computadora baja de unos 20 cuadros por segundo, la simulación se ralentiza: es una simplificación deliberada, no una garantía de tiempo real exacto.
6. **Colisión discreta:** revisamos superposiciones después de cada movimiento. Las velocidades, tamaños y límite de `dt` de esta práctica mantienen pasos pequeños. Aumentar mucho la rapidez puede hacer que un objeto atraviese otro entre cuadros; no supongas que `colliderect` detecta todo el trayecto.
7. **Panel:** el cuarto argumento `2` en el dibujo del campo hace un contorno. Es una referencia visual; los límites matemáticos son los que mantienen al jugador dentro.
8. **Inicio:** `if __name__ == "__main__":` ejecuta `main()` cuando abres el archivo como programa; importarlo para probar funciones no inicia la ventana.

## Errores frecuentes

| Problema | Qué revisar |
|---|---|
| `No module named pygame` | Instalación e intérprete de ejecución deben coincidir. |
| Error de importación extraño | No uses `pygame.py` como nombre de archivo o carpeta del proyecto. |
| Ventana “no responde” | Procesa eventos en cada vuelta; evita `input`, `sleep` y ciclos internos que esperen una tecla. |
| El jugador no aparece | Dibuja después del fondo y antes de `flip`; revisa coordenadas. |
| Deja un rastro | Falta llenar el fondo en cada cuadro. |
| Se mueve apenas y vuelve al inicio | Inicializaste la posición dentro del ciclo. |
| Se mueve muy rápido o diferente entre equipos | Revisa píxeles por segundo y la multiplicación por `dt`. |
| Sale parcialmente de la ventana | El límite debe considerar ancho y alto completos. |
| La colisión está atrasada | Sincroniza `Rect` después de cambiar la posición. |
| Los puntos crecen sin parar | Retira el objeto o desactívalo al recogerlo. |
| Se saltan baterías al eliminarlas | Recorre una copia de la lista. |
| La dificultad cambia el sentido del dron | Mantén rapidez y dirección en datos separados. |
| Pierde vidas en cuadros consecutivos | Revisa la protección y que su dato no se reinicie en cada vuelta. |
| La pausa no permite cerrar | Sacar eventos del bloque que depende de `jugando`. |
