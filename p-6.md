### Paso 13. Primer juego completo: recorrer el pasillo

**Archivo nuevo:** crea `pasillo.py` y pega este programa completo.

```python
ANCHO = 10
px = 3
jugando = True

def dibujar_pasillo(ancho, posicion):
    izquierda = "." * (posicion - 1)
    derecha = "." * (ancho - 2 - posicion)
    return "|" + izquierda + "@" + derecha + "|"

while jugando:
    print(dibujar_pasillo(ANCHO, px))
    tecla = input("A/D: mover; X: terminar. Luego Enter: ").strip().lower()
    if tecla == "x":
        jugando = False
    elif tecla == "a" or tecla == "d":
        dx = 0
        if tecla == "a":
            dx = -1
        elif tecla == "d":
            dx = 1
        nx = px + dx
        if nx > 0 and nx < ANCHO - 1:
            px = nx
        else:
            print("¡Hay una pared!")
    else:
        print("Orden no válida. Escribe a, d o x.")

print("Fin del recorrido")
```

**Lee el ciclo en orden:** dibujar, pedir una orden, proponer posición, revisar límites y actualizar si está permitido. Al volver al principio se imprime el nuevo estado.

- `while jugando` repite mientras la variable sea `True`.
- `or` permite reconocer cualquiera de las dos órdenes de movimiento.
- `jugando = False` hace que el ciclo termine en su próxima comprobación.
- Las posiciones se inicializan antes del ciclo para no reiniciarlas en cada turno.

**Resultado esperado:** el robot se mueve entre las paredes y nunca las reemplaza. Cada turno imprime otra línea; por ahora queremos conservar el historial.

**Misión:** llega a ambos extremos, intenta atravesar cada pared y termina con `x`.

**Explica:** ¿qué ocurriría si `px = 3` estuviera dentro del `while`?

## Parte C. Unir las piezas y jugar

### Paso 23. Segundo programa completo: explorar una habitación

**Archivo nuevo:** crea `escape.py` y pega este programa. No agregues el contenido de `experimentos.py` ni de `pasillo.py`.

Cada función organiza una operación que ya practicamos. Lee sus explicaciones debajo antes de ejecutarlo.

```python
ANCHO = 12
ALTO = 7
JUGADOR = "@"

def poner_caracter(linea, x, simbolo):
    return linea[:x] + simbolo + linea[x + 1:]

def crear_mapa():
    pared = "#" * ANCHO
    interior = "#" + " " * (ANCHO - 2) + "#"
    filas = [pared] + [interior] * (ALTO - 2) + [pared]
    return filas

def dibujar(mapa, px, py):
    pantalla = mapa.copy()
    pantalla[py] = poner_caracter(pantalla[py], px, JUGADOR)
    print("\n".join(pantalla))

def puede_mover(mapa, nx, ny):
    if nx < 0 or nx >= ANCHO:
        return False
    if ny < 0 or ny >= ALTO:
        return False
    if mapa[ny][nx] == "#":
        return False
    return True

# INICIO DE LA PARTIDA
mapa = crear_mapa()
px = 1
py = 1
jugando = True

while jugando:
    dibujar(mapa, px, py)
    tecla = input("WASD: mover; X: terminar. Luego Enter: ").strip().lower()
    if tecla == "x":
        jugando = False
    elif tecla in ("w", "a", "s", "d"):
        dx = 0
        dy = 0
        if tecla == "a":
            dx = -1
        elif tecla == "d":
            dx = 1
        elif tecla == "w":
            dy = -1
        elif tecla == "s":
            dy = 1
        nx = px + dx
        ny = py + dy
        if puede_mover(mapa, nx, ny):
            px = nx
            py = ny
        else:
            print("¡Hay una pared!")
    else:
        print("Orden no válida. Usa w, a, s, d o x.")

print("Fin de la exploración")
```

| Parte | Responsabilidad |
|---|---|
| `poner_caracter` | Construir una fila con un símbolo reemplazado. |
| `crear_mapa` | Crear el terreno una sola vez al iniciar. |
| `dibujar` | Crear una imagen temporal del terreno y el robot. |
| `puede_mover` | Devolver `False` si hay un límite o pared; `True` si se permite avanzar. |
| Programa principal | Guardar la posición y repetir los turnos. |

`tecla in ("w", "a", "s", "d")` pregunta si el texto coincide con alguno de los elementos de esa tupla. No significa que se acepten varias teclas a la vez: `wd` es una orden inválida.

Los `return False` terminan esa llamada a la función en cuanto se encuentra un problema. Solo se llega al último `return True` si ninguna comprobación bloqueó la posición.

**Resultado esperado:** el robot aparece en `(1, 1)` y se mueve por el interior. El mapa se imprime nuevamente en cada turno; no se borra la pantalla todavía.

**Pruebas:** desde el inicio intenta `w` y `a` (debe bloquearlos); luego `d` y `s` (debe aceptarlos). Escribe `hola` (debe avisar sin moverse) y `x` (debe terminar).

### Paso 29. Punto de comprobación: juego de escape completo

Si tus cambios funcionan, conserva tu solución. Si perdiste la ubicación de una instrucción, compara tu `escape.py` con esta versión. **No pegues este programa debajo del anterior:** es el contenido completo del archivo después del paso 28.

```python
ANCHO = 12
ALTO = 7
JUGADOR = "@"
SALIDA_X = ANCHO - 1
SALIDA_Y = ALTO // 2
PARED_Y = 2
PASO_X = 4

def poner_caracter(linea, x, simbolo):
    return linea[:x] + simbolo + linea[x + 1:]

def crear_mapa():
    pared = "#" * ANCHO
    interior = "#" + " " * (ANCHO - 2) + "#"
    filas = [pared] + [interior] * (ALTO - 2) + [pared]
    filas[PARED_Y] = "#" * ANCHO
    filas[PARED_Y] = poner_caracter(filas[PARED_Y], PASO_X, " ")
    filas[SALIDA_Y] = poner_caracter(filas[SALIDA_Y], SALIDA_X, "E")
    return filas

def dibujar(mapa, px, py):
    pantalla = mapa.copy()
    pantalla[py] = poner_caracter(pantalla[py], px, JUGADOR)
    print("\n".join(pantalla))

def puede_mover(mapa, nx, ny):
    if nx < 0 or nx >= ANCHO:
        return False
    if ny < 0 or ny >= ALTO:
        return False
    if mapa[ny][nx] == "#":
        return False
    return True

# INICIO DE LA PARTIDA
mapa = crear_mapa()
px = 1
py = 1
jugando = True
escapo = False
movimientos = 0

while jugando:
    dibujar(mapa, px, py)
    print("Movimientos:", movimientos)
    tecla = input("WASD: mover; X: terminar. Luego Enter: ").strip().lower()
    if tecla == "x":
        jugando = False
    elif tecla in ("w", "a", "s", "d"):
        dx = 0
        dy = 0
        if tecla == "a":
            dx = -1
        elif tecla == "d":
            dx = 1
        elif tecla == "w":
            dy = -1
        elif tecla == "s":
            dy = 1
        nx = px + dx
        ny = py + dy
        if puede_mover(mapa, nx, ny):
            px = nx
            py = ny
            movimientos = movimientos + 1
            if px == SALIDA_X and py == SALIDA_Y:
                escapo = True
                jugando = False
        else:
            print("¡Hay una pared!")
    else:
        print("Orden no válida. Usa w, a, s, d o x.")

dibujar(mapa, px, py)
if escapo:
    print("¡Misión cumplida! El robot llegó a la salida.")
else:
    print("Terminaste la partida antes de escapar.")
print("Movimientos realizados:", movimientos)
```

**Verifica antes de continuar:** el mapa mide 12×7, el jugador inicia en `(1, 1)`, la pared interna ocupa la fila 2, su paso está en la columna 4 y la salida está en `(11, 3)`.
