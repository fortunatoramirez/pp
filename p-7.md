## La misión

Nuestro robot ya sabe recorrer la estación y responder al teclado sin Enter. Ahora debe recuperar **tres baterías `*`** antes de escapar. La estación tiene fugas de energía `~`, la salida `E` necesita todas las baterías y quedan **90 segundos**.

El objetivo es construir un juego con reglas, tiempo y estados, conservando el mapa y las funciones que ya conoces. Al terminar podrás explicar qué datos cambian cuando ocurre una acción y por qué dibujar es distinto de actualizar el juego.

| Elemento o control | Función |
|---|---|
| `@` | Robot; inicia en `(1, 1)`. |
| `#` | Pared; bloquea el paso. |
| `*` | Batería; desaparece al recogerla y suma 10 puntos. |
| `~` | Fuga; resta una vida cada vez que entras a esa casilla. |
| `E` | Salida; permite ganar solamente con las tres baterías. |
| `W/A/S/D` | Mover, sin Enter. |
| `P` | Pausar o continuar; en pausa no avanzan el robot ni el reloj. |
| `R` | Reiniciar después de ganar o perder. |
| `X` | Cerrar en cualquier estado. |

Tienes tres vidas. Pierdes al llegar a cero vidas o agotar el tiempo. La salida puede pisarse antes de reunir las baterías, pero no produce victoria. Estar quieto sobre una fuga no resta vidas repetidamente; salir y volver a entrar sí.

## Paso 7. Medir tiempo real

**Archivo:** reemplaza `experimentos7.py`.

```python
import time

anterior = time.monotonic()
time.sleep(0.2)
ahora = time.monotonic()
dt = ahora - anterior
print("Segundos transcurridos:", dt)
```

`time.monotonic()` permite medir intervalos sin depender de cambios en la hora del sistema. Restar dos lecturas produce el tiempo transcurrido. Llamaremos **`dt`** a ese intervalo; no tiene que ser exactamente 0.2.

En el juego leeremos el reloj en cada vuelta. Restaremos `dt` al tiempo restante solamente si el modo es `jugando`. Actualizaremos la referencia `anterior` **también durante la pausa**, para no descontar toda la pausa al continuar.

La espera `time.sleep(0.01)` reduce el trabajo del ciclo; **no significa que cada vuelta dure exactamente 10 ms**. Por eso no descontaremos una cantidad fija por vuelta.

## Paso 8. Decidir las reglas antes de programar

Para una orden de movimiento:

1. Traducir la tecla a `dx` y `dy`.
2. Calcular `nx` y `ny` sin cambiar todavía la posición.
3. Consultar `puede_mover`. Si hay pared, dejar posición, vidas y contador como estaban.
4. Si se acepta, guardar la posición y sumar un movimiento.
5. Recoger la batería de esa casilla, si existe.
6. Aplicar daño si se entró a una fuga. Con cero vidas, cambiar a `derrota`.
7. Comprobar la salida. Con baterías pendientes, mostrar un aviso; sin pendientes, cambiar a `victoria`.
8. Dibujar el resultado.

**Colisión** aquí significa coincidir en una casilla. Una pared impide entrar; una batería se recoge; una fuga permite entrar, pero hace daño. No todas las colisiones tienen la misma respuesta.

El reloj se revisará incluso sin teclas. Si se agota en una vuelta, la derrota tendrá prioridad sobre el movimiento de esa vuelta. La tecla `X` seguirá cerrando el programa.

**Antes de avanzar:** describe qué debe pasar si intentas caminar contra una pared mientras estás sobre una fuga. No aceptaste otro movimiento: no debes perder otra vida.

## Paso 9. Integrar la misión

**Archivo:** reemplaza todo `rescate.py` por este programa. No lo pegues debajo del juego anterior ni agregues los experimentos. Después revisa las funciones en el orden del paso 10.

```python
import msvcrt
import time
import os
import math

ANCHO = 12
ALTO = 7
JUGADOR = "@"
SALIDA_X = ANCHO - 1
SALIDA_Y = ALTO // 2
PARED_Y = 2
PASO_X = 4
TIEMPO_INICIAL = 90.0
TOTAL_BATERIAS = 3
PELIGROS = [(6, 3), (7, 3), (8, 3)]


def leer_tecla():
    if not msvcrt.kbhit():
        return ""
    tecla = msvcrt.getwch()
    if tecla == "\x00" or tecla == "\xe0":
        msvcrt.getwch()
        return ""
    return tecla.lower()


def poner_caracter(linea, x, simbolo):
    return linea[:x] + simbolo + linea[x + 1:]


def crear_mapa():
    pared = "#" * ANCHO
    interior = "#" + " " * (ANCHO - 2) + "#"
    filas = [pared] + [interior] * (ALTO - 2) + [pared]
    filas[PARED_Y] = "#" * ANCHO
    filas[PARED_Y] = poner_caracter(filas[PARED_Y], PASO_X, " ")
    filas[SALIDA_Y] = poner_caracter(filas[SALIDA_Y], SALIDA_X, "E")
    return filas


def puede_mover(mapa, nx, ny):
    if nx < 0 or nx >= ANCHO:
        return False
    if ny < 0 or ny >= ALTO:
        return False
    if mapa[ny][nx] == "#":
        return False
    return True


def nueva_partida():
    return {
        "px": 1,
        "py": 1,
        "vidas": 3,
        "puntos": 0,
        "movimientos": 0,
        "baterias": [(2, 1), (2, 5), (9, 4)],
        "tiempo": TIEMPO_INICIAL,
        "modo": "jugando",
        "mensaje": "Recoge las tres baterías y llega a E."
    }


def mover_jugador(mapa, estado, tecla):
    dx = 0
    dy = 0
    if tecla == "a":
        dx = -1
    elif tecla == "d":
        dx = 1
    elif tecla == "w":
        dy = -1
    elif tecla == "s":
        dy = 1
    else:
        return

    nx = estado["px"] + dx
    ny = estado["py"] + dy
    if not puede_mover(mapa, nx, ny):
        estado["mensaje"] = "¡Hay una pared! Busca el hueco."
        return

    estado["px"] = nx
    estado["py"] = ny
    estado["movimientos"] = estado["movimientos"] + 1
    estado["mensaje"] = "Explora la estación."
    posicion = (nx, ny)

    if posicion in estado["baterias"]:
        estado["baterias"].remove(posicion)
        estado["puntos"] = estado["puntos"] + 10
        estado["mensaje"] = "¡Batería recuperada! +10 puntos."

    if posicion in PELIGROS:
        estado["vidas"] = estado["vidas"] - 1
        estado["mensaje"] = "¡Fuga de energía! Perdiste una vida."
        if estado["vidas"] <= 0:
            estado["modo"] = "derrota"
            estado["mensaje"] = "El robot se quedó sin vidas. R: reintentar."
            return

    if posicion == (SALIDA_X, SALIDA_Y):
        if len(estado["baterias"]) == 0:
            estado["modo"] = "victoria"
            estado["mensaje"] = "¡Rescate completo! R: jugar otra vez."
        else:
            estado["mensaje"] = "Faltan baterías. Regresa a buscarlas."


def actualizar_tiempo(estado, dt):
    if estado["modo"] != "jugando":
        return
    estado["tiempo"] = max(0.0, estado["tiempo"] - dt)
    if estado["tiempo"] <= 0:
        estado["modo"] = "derrota"
        estado["mensaje"] = "¡Se agotó el tiempo! R: reintentar."


def procesar_entrada(mapa, estado, tecla):
    if tecla == "p":
        if estado["modo"] == "jugando":
            estado["modo"] = "pausa"
            estado["mensaje"] = "Pausa. Pulsa P para continuar."
        elif estado["modo"] == "pausa":
            estado["modo"] = "jugando"
            estado["mensaje"] = "¡Continúa el rescate!"
    elif estado["modo"] == "jugando":
        if tecla in ("w", "a", "s", "d"):
            mover_jugador(mapa, estado, tecla)
        elif tecla != "":
            estado["mensaje"] = "Usa WASD, P o X. R funciona al terminar."


def dibujar(mapa, estado):
    os.system("cls")
    pantalla = mapa.copy()
    for x, y in PELIGROS:
        pantalla[y] = poner_caracter(pantalla[y], x, "~")
    for x, y in estado["baterias"]:
        pantalla[y] = poner_caracter(pantalla[y], x, "*")
    px = estado["px"]
    py = estado["py"]
    pantalla[py] = poner_caracter(pantalla[py], px, JUGADOR)
    print("\n".join(pantalla))
    recogidas = TOTAL_BATERIAS - len(estado["baterias"])
    print("Baterías:", recogidas, "/", TOTAL_BATERIAS)
    print("Vidas:", estado["vidas"], "Puntos:", estado["puntos"])
    print("Tiempo:", math.ceil(estado["tiempo"]), "s")
    print("Movimientos:", estado["movimientos"], "Modo:", estado["modo"])
    print("WASD: mover | P: pausa | R: reiniciar al terminar | X: cerrar")
    print("*: batería | ~: fuga | E: salida")
    print(estado["mensaje"])


def main():
    mapa = crear_mapa()
    estado = nueva_partida()
    dibujar(mapa, estado)
    anterior = time.monotonic()

    while True:
        ahora = time.monotonic()
        dt = ahora - anterior
        anterior = ahora
        segundos_antes = math.ceil(estado["tiempo"])
        modo_antes = estado["modo"]

        actualizar_tiempo(estado, dt)
        tecla = leer_tecla()
        if tecla == "x":
            break

        if tecla == "r" and estado["modo"] in ("victoria", "derrota"):
            estado = nueva_partida()
            anterior = time.monotonic()
        else:
            procesar_entrada(mapa, estado, tecla)

        cambio_reloj = math.ceil(estado["tiempo"]) != segundos_antes
        cambio_modo = estado["modo"] != modo_antes
        if tecla != "" or cambio_reloj or cambio_modo:
            dibujar(mapa, estado)

        time.sleep(0.01)

    print("Juego cerrado. Resultado:", estado["modo"])


if __name__ == "__main__":
    main()
```

## Paso 10. Leer la integración sin perderse

Revisa una función a la vez. No avances hasta poder explicar su responsabilidad.

1. **`nueva_partida`:** construye un diccionario y una lista de baterías nuevos cada vez. Por eso `R` recupera también los objetos que habías recogido.
2. **`mover_jugador`:** conserva los desplazamientos y las comprobaciones anteriores. Después del movimiento aceptado resuelve baterías, daño y salida. Un `return` sin valor termina la función inmediatamente.
3. **`actualizar_tiempo`:** funciona sin teclado. `max(0.0, ...)` evita mostrar tiempo negativo. En pausa, victoria o derrota regresa sin descontar.
4. **`procesar_entrada`:** consulta el modo antes de permitir movimiento. `P` alterna pausa; en un resultado final ya no puede reactivar la partida.
5. **`dibujar`:** mezcla terreno, peligros, baterías y robot, en ese orden. El robot se dibuja al final y cubre temporalmente el símbolo bajo él. Esta función no recoge objetos ni resta vidas.
6. **`main`:** coordina reloj, entrada, reglas y dibujo. `break` termina su ciclo cuando se pulsa `X`. Reiniciar reemplaza el estado completo.

`math.ceil` redondea hacia arriba: con 2.4 segundos restantes se muestran 3. Así el indicador no anuncia cero cuando todavía queda una fracción de segundo.

La condición de dibujo permite actualizar la pantalla cuando hay una tecla, cambia el segundo visible o cambia el modo. **El reloj se calcula en cada vuelta; la pantalla no necesita limpiarse en todas ellas.** Puede seguir habiendo algo de parpadeo por `cls`; si molesta, comenta solamente esa línea para revisar la lógica con un historial de pantallas.

La última condición, `if __name__ == "__main__":`, llama a `main()` cuando ejecutas el archivo directamente. Si otro programa lo importa para revisar sus funciones, no inicia el juego automáticamente.

## Errores frecuentes

| Problema | Qué revisar |
|---|---|
| `No module named msvcrt` | Ejecuta con Python para Windows, fuera de WSL. |
| El juego exige Enter | Ejecutaste otro archivo o conservaste `input()`. |
| `KeyError` | Alguna clave del diccionario está escrita de otra manera. |
| `ValueError` al recoger | Llamaste a `remove` sin verificar `in` o retiraste el objeto dos veces. |
| Pierdes vidas sin moverte | Aplicaste daño en cada vuelta del ciclo en lugar de después de un movimiento aceptado. |
| Las baterías vuelven al dibujar | Creaste la lista dentro de `dibujar` o dentro del ciclo. |
| Reiniciar conserva objetos recogidos | No estás creando el estado y su lista nuevamente. |
| El tiempo cae de golpe al continuar | Dejaste de actualizar `anterior` mientras estaba pausado. |
| El tiempo avanza solo al tocar teclas | Colocaste `actualizar_tiempo` dentro de la condición de entrada. |
| La pantalla parpadea demasiado | Revisa que `dibujar` no se ejecute incondicionalmente en cada vuelta. |
| Un objeto se oculta o no se alcanza | Revisa `(x, y)`, paredes y superposiciones. |
| Mantener P pausa y continúa varias veces | El sistema repite caracteres; usa pulsaciones breves. |

**Meta de la práctica:** poder seguir una acción desde la entrada hasta el cambio de datos y su representación, y explicar qué sigue ocurriendo cuando el jugador no toca el teclado.
