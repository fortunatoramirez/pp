## Paso 1. Entender qué cambia

Antes utilizábamos:

```python
tecla = input("Orden: ").strip().lower()
```

`input` recibe una línea completa después de Enter. Ahora leeremos caracteres individuales. Escribir rápidamente `ddd` generará tres órdenes, no una cadena que el juego deba comparar con `"ddd"`.

En esta práctica llamaremos **evento de entrada** a una tecla disponible para procesar. Usaremos **sondeo**: el programa consulta repetidamente si hay entrada. No instalaremos un detector global de teclado ni una función que se ejecute automáticamente al soltar una tecla.

## Paso 2. Leer una tecla sin Enter

**Archivo:** reemplaza `pruebas_teclado.py` por:

```python
import msvcrt

print("Presiona una letra, sin Enter:")
tecla = msvcrt.getwch()
print("Recibí:", tecla)
```

`import` permite utilizar un módulo. `getwch()` obtiene un carácter como texto y no lo escribe automáticamente en pantalla; nuestro `print` lo muestra después.

**Prueba:** ejecuta y pulsa `d`. Debe aparecer el resultado inmediatamente, sin Enter. Repite con `D`.

**Atención:** `getwch()` por sí sola espera si todavía no hay una tecla. Quitar Enter no significa que el programa haya dejado de esperar entrada.

## Paso 3. Consultar antes de leer

**Archivo:** reemplaza `pruebas_teclado.py` por:

```python
import msvcrt
import time

print("Presiona letras; X termina. No uses Enter.")
jugando = True

while jugando:
    if msvcrt.kbhit():
        tecla = msvcrt.getwch().lower()
        print("Recibí:", repr(tecla))
        if tecla == "x":
            jugando = False
    time.sleep(0.01)
```

- `kbhit()` consulta si existe una tecla pendiente de lectura.
- Si existe, `getwch()` la consume: esa entrada deja de estar pendiente.
- `.lower()` permite tratar `D` y `d` como la misma orden.
- `repr()` permite ver caracteres especiales: Enter normalmente aparece como `'\r'`.
- `time.sleep(0.01)` introduce una pausa de 0.01 segundos (10 ms) para evitar consultar continuamente a máxima velocidad. No es un temporizador exacto ni fija la velocidad del personaje.

**Prueba:** espera unos segundos sin tocar el teclado. No deben imprimirse mensajes nuevos. Luego pulsa `a`, `D` y `x`, por separado.

El ciclo sigue dando vueltas aunque no haya entrada. Así, más adelante podríamos añadir tareas que se revisen sin esperar una orden del jugador.

## Paso 4. Preparar una función de lectura

Las flechas y algunas teclas de función pueden producir una secuencia de dos lecturas: primero un prefijo especial y después un código. En esta práctica las ignoraremos completas para que su segundo código no se interprete como una letra.

**Archivo:** reemplaza `pruebas_teclado.py` por:

```python
import msvcrt
import time

def leer_tecla():
    if not msvcrt.kbhit():
        return ""

    tecla = msvcrt.getwch()
    if tecla == "\x00" or tecla == "\xe0":
        msvcrt.getwch()
        return ""

    return tecla.lower()

print("WASD: órdenes; X: salir. Sin Enter.")
jugando = True

while jugando:
    tecla = leer_tecla()
    if tecla == "x":
        jugando = False
    elif tecla in ("w", "a", "s", "d"):
        print("Orden de movimiento:", tecla)
    elif tecla != "":
        print("Tecla no válida:", repr(tecla))
    time.sleep(0.01)
```

`not` niega la condición. Si no hay entrada, devolvemos `""`, un string vacío. Los textos `"\x00"` y `"\xe0"` representan caracteres especiales; no debes escribirlos con el teclado.

| Situación | Resultado de `leer_tecla()` |
|---|---|
| No hay entrada pendiente | `""` |
| Se pulsa `D` | `"d"` |
| Se pulsa `x` | `"x"` |
| Se pulsa una flecha con prefijo especial | Consume la secuencia y devuelve `""` |
| Se pulsa Enter | Devuelve su carácter; no es una orden de movimiento |

**Prueba:** pulsa letras, una flecha, Enter y finalmente `x`. Las flechas deben ignorarse; Enter no mueve nada. No uses `.strip()`: queremos distinguir una tecla inválida, como espacio, de la ausencia de entrada.

**Explica:** ¿por qué sería incorrecto mostrar «Tecla inválida» cada vez que la función devuelve `""`?

## Paso 6. Organizar el ciclo para consultar sin detener el juego

Ahora quitaremos la espera interna del paso anterior. La estructura será:

1. Dibujar el estado inicial una vez.
2. Consultar el teclado en cada vuelta del `while`.
3. Si hay una orden, procesarla y actualizar el dibujo.
4. Si no hay entrada, conservar la pantalla y continuar el ciclo.

**No dibujes y limpies en todas las vueltas:** produciría parpadeo innecesario aunque el jugador no haga nada.

Además, un aviso como «¡Hay una pared!» se guardará en una variable `mensaje`. Primero limpiaremos la pantalla, luego dibujaremos y finalmente mostraremos ese mensaje. Así permanece visible hasta la siguiente orden, sin ninguna pausa con Enter.

## Paso 7. Integrar la versión completa

**Archivo:** reemplaza todo `escape_teclado.py` por el siguiente programa. No lo agregues debajo del anterior. Compara las funciones del mapa con tu práctica original: las reglas de movimiento se conservan.

```python
import msvcrt
import time
import os

ANCHO = 12
ALTO = 7
JUGADOR = "@"
SALIDA_X = ANCHO - 1
SALIDA_Y = ALTO // 2
PARED_Y = 2
PASO_X = 4

def leer_tecla():
    if not msvcrt.kbhit():
        return ""
    tecla = msvcrt.getwch()
    if tecla == "\x00" or tecla == "\xe0":
        msvcrt.getwch()
        return ""
    return tecla.lower()

def poner_caracter(linea, x, simbolo):
    return linea[:x] + simbolo + linea[x + 1:]

def crear_mapa():
    pared = "#" * ANCHO
    interior = "#" + " " * (ANCHO - 2) + "#"
    filas = [pared] + [interior] * (ALTO - 2) + [pared]
    filas[PARED_Y] = "#" * ANCHO
    filas[PARED_Y] = poner_caracter(filas[PARED_Y], PASO_X, " ")
    filas[SALIDA_Y] = poner_caracter(filas[SALIDA_Y], SALIDA_X, "E")
    return filas

def dibujar(mapa, px, py, movimientos, mensaje):
    os.system("cls")
    pantalla = mapa.copy()
    pantalla[py] = poner_caracter(pantalla[py], px, JUGADOR)
    print("\n".join(pantalla))
    print("Movimientos:", movimientos)
    print("WASD: mover; X: terminar. Sin Enter.")
    print(mensaje)

def puede_mover(mapa, nx, ny):
    if nx < 0 or nx >= ANCHO:
        return False
    if ny < 0 or ny >= ALTO:
        return False
    if mapa[ny][nx] == "#":
        return False
    return True

# INICIO DE LA PARTIDA
mapa = crear_mapa()
px = 1
py = 1
jugando = True
escapo = False
movimientos = 0
mensaje = "Llega a E pasando por el hueco de la pared."
dibujar(mapa, px, py, movimientos, mensaje)

while jugando:
    tecla = leer_tecla()

    if tecla != "":
        if tecla == "x":
            jugando = False
            mensaje = "Terminaste la partida antes de escapar."
        elif tecla in ("w", "a", "s", "d"):
            dx = 0
            dy = 0
            if tecla == "a":
                dx = -1
            elif tecla == "d":
                dx = 1
            elif tecla == "w":
                dy = -1
            elif tecla == "s":
                dy = 1

            nx = px + dx
            ny = py + dy
            if puede_mover(mapa, nx, ny):
                px = nx
                py = ny
                movimientos = movimientos + 1
                mensaje = "Movimiento aceptado."
                if px == SALIDA_X and py == SALIDA_Y:
                    escapo = True
                    jugando = False
                    mensaje = "¡Misión cumplida! El robot llegó a la salida."
            else:
                mensaje = "¡Hay una pared!"
        else:
            mensaje = "Tecla no válida. Usa W, A, S, D o X."

        dibujar(mapa, px, py, movimientos, mensaje)

    time.sleep(0.01)

if escapo:
    print("Resultado: victoria.")
else:
    print("Resultado: abandono.")
print("Movimientos realizados:", movimientos)
```

### Leer el programa por partes

- **Entrada:** `leer_tecla()` entrega un carácter o `""`.
- **Filtro:** `if tecla != "":` evita procesar la ausencia de entrada como un error.
- **Decisión:** `x` termina; WASD propone un desplazamiento; las demás teclas muestran un aviso.
- **Validación:** `puede_mover` revisa los límites y el terreno antes de aceptar la posición.
- **Estado:** solamente un movimiento aceptado actualiza `px`, `py` y el contador.
- **Salida visual:** `dibujar` recibe también el contador y el mensaje. Todas sus llamadas deben pasar los cinco argumentos.

`os.system("cls")` pide a la terminal de Windows que limpie la pantalla. Si produce problemas o demasiado parpadeo, comenta solamente esa línea; volverás a ver el historial, pero el teclado y las reglas seguirán funcionando.

**La sangría importa:** `dibujar(...)` dentro del ciclo queda dentro de `if tecla != ""`, pero fuera de sus decisiones internas. `time.sleep(...)` queda dentro del `while`, fuera de ese `if`, para descansar también cuando no hay teclas.

## Paso 8. Comprender qué pasa al mantener una tecla

Una pulsación breve normalmente produce una orden. Si mantienes una letra, Windows puede generar repeticiones después de un retraso. El robot puede seguir avanzando por esas entradas repetidas.

Esta versión **no detecta cuándo sueltas la tecla**, no permite movimiento diagonal simultáneo y no garantiza un desplazamiento por pulsación física. Tampoco fija una velocidad uniforme: procesa caracteres conforme llegan. Para las pruebas, pulsa y suelta cada letra por separado.

Las entradas pendientes se procesan en orden. Si escribes mucho más rápido de lo que se dibuja, puede quedar una cola por procesar. La pausa de 10 ms no elimina esa cola.

**Experimento:** mantén `d` un momento y suelta. Describe la diferencia con tres pulsaciones breves. No cambies las colisiones: el jugador debe detenerse ante la pared.
